# セクシー女優図鑑 視覚システム(役割の正本)

表現の値は `design/visual-tokens.md`。ここは役割と禁止事項だけを書く。

## 1. 面と浮きの役割
| 段 | 役割 | 使用条件・上限 |
|---|---|---|
| 地(bg) | ページ背景。作業領域の既定の面 | 静的コンテンツの既定。囲まない |
| 主面(surface) | 作業対象そのもの(散布図の描画面、入力欄、写真) | 静的コンテンツが使ってよい上限。カード化は「押せる 1 件」と「比較のために並べる 1 件」に限る |
| ナビ面 | ヘッダー(文脈：アプリ名・ログアウト)と、コレクションのビュー切替 | 主面と同じ面に見せない。地より一段暗い／明るいトーンと罫線の 2 手掛かりで区分する。作業対象より弱い文字 |
| 一時面 | 取り消しトースト、スライダーの名前チップ | 影を使ってよいのはここから上 |
| 浮遊面 | OS の confirm(使わない方針)、将来のメニュー | 最上位。静的要素に使わない |

- 静的コンテンツは「地」と「主面」まで。影は一時面以上に予約する。
- 1 要素に重ねてよい浮かせ資源(面色差・枠・彩色・影)は 2 つまで。

## 2. 色の役割
| 色 | 役割 | 使用条件 |
|---|---|---|
| primary | 主操作 1 つ(塗りボタン)、散布図の点、自分のスライダーつまみ、選択中のビュー切替 | 1 画面に塗りボタンは 1 つ。文字色には使わない |
| accent | 散布図で固定中・ホバー中の点 | 点だけ。文字・バッジ・警告に流用しない |
| secondary | 他人(既存登録者)のアバター面 | アバター以外に使わない |
| danger | 取り消せない操作の文字(削除) | 削除とエラー文のみ |
| muted | 文脈情報・ラベル・補助文 | 作業対象の値には使わない |
| ink | 本文・値 | 既定 |

- 無彩色(ink / muted / axis / border)が既定。分類ごとの色分けはしない。
- 状態は色だけで表さない(固定中の点は大きさ + 枠線も変える)。

## 3. 操作の階層
| 段 | 乗せる操作 | 同時表示 |
|---|---|---|
| 主 | そのビューのゴールに直結する確定操作(保存、ログイン、最初の 1 人を登録) | 1 画面 1 つ |
| 従 | 主を補助する確定操作(編集に入る、写真を選ぶ、目安にする) | 枠線だけ。複数可 |
| 補助 | 取り消し・閉じる・外す・キャンセル・ログアウト | 文字だけ |
| 危険 | 削除 | 文字だけ + danger 色。主の表現にしない |

- ナビの選択状態(ビュー切替の現在)は操作の段に乗せない。塗りではなく下線または薄い面で示す。
- 追加(Create)はコレクションの近くにアイコンボタン 1 つ。ナビ項目にしない。

## 4. 部品の役割
- テキスト＝名前・値。タグ・バッジはこの製品では使わない(分類も状態も存在しない)。
- チップ＝軽い操作(ビュー切替の 2 択)。押した先が文言から分かること。
- ボタン＝確定操作。押せる見た目(塗りか枠線)と押せない見た目(文字だけ)を区別する。
- リンク＝一覧の行・カード全体(押すと詳細へ)。行の中に「詳細を見る」ボタンを置かない。
- 補足文は「操作しないと分からないこと」だけに限る(例：最初の 1 人には基準がない)。寸法や内部処理の説明は載せない。
