# UI設計：ui-redesign

## 規模
標準(全画面・ナビゲーション構造の作り替え)

## メインオブジェクト
【メインオブジェクト1】女優
  プロパティ: 名前, 写真, 生年月日(→年齢), 身長, カップ, 肉付き, 骨格, 顔
  操作: 登録(Create), 参照(Read), 更新(Update), 削除(Delete)
  関連: なし(ユーザー単位のコレクションのみ)

抽出した名詞と分類：
- 女優 … メイン
- 写真・名前・生年月日・年齢・身長・カップ・肉付き・骨格・顔 … 女優のプロパティ(年齢は生年月日からの派生値)
- 横軸・縦軸 … 散布図ビューの表示パラメータ(操作の引数。オブジェクトではない)
- 既存登録者・基準 … 相対指定のときに参照する「他の女優」=同じコレクション
- バスト cm … カップ入力の補助引数(保存しない)
- 一覧・散布図 … 女優コレクションの 2 つの表示形式(ビュー。オブジェクトではない)
- ユーザー・ログイン … 文脈。画面内のオブジェクトにしない

チェック：メインは 1 個。内部 ID・user_id・created_at はプロパティに含めない。「写真あり／なし」を状態にしない。

## ビュー構成とナビゲーション
```
女優コレクション(表示形式: 一覧 / 散布図) ─── 選択 ───▶ 女優シングル(閲覧 ⇄ 編集)
        │                                                 ├ 更新(同じビュー内で編集状態へ)
        └ 登録 ───▶ 女優シングル(新規状態) ──保存──▶ コレクション(一覧)   └ 削除(即時 + 取り消し)
```
- ルートナビは置かない(メインオブジェクトが 1 つ)。ヘッダーは文脈(アプリ名・ログアウト)のみ。
- コレクションの表示形式切替「一覧｜散布図」は名詞ラベルのチップ 2 択。
- 散布図ビューの内側で、点のホバー(PC)／タップ(スマホ)で女優の要約カードを出す。PC はクリックで固定して複数枚を比較、スマホは 1 枚だけ。カードを押すとシングルへ。
- シングルは 1 ルート(`/a/:id`)で閲覧状態と編集状態を切り替える。新規は同じビューの新規状態(`/new`)。
- 追加後は要件どおり一覧へ戻る。更新後は同じシングルの閲覧状態に戻る。
- シングルからの戻り先は「来たビュー」(一覧から来たら一覧、散布図から来たら散布図)。ヘッダーの戻りラベルも「‹ 一覧」「‹ 散布図」と切り替える。散布図の軸選択と固定状態は画面を離れても保持し、戻ったときに続きから見られる。
- 新規のキャンセル・削除後の遷移先も同じく「来たビュー」。

## 既存構造の扱い
作り替える。理由：(1) 下部タブに動詞「追加」が入りタスク指向になっている (2) 詳細と編集が別画面で、同一オブジェクトへの操作が分散している (3) 2 ステップのフォームに narrow exception の根拠がない(順序依存なし、1 画面に収まる量)。散布図のホバー/固定と PC 2 ペインは直近で合意済みの挙動なので維持する。

## レイアウトパターン
- 3-1 ルートナビ：なし。ヘッダー(ナビ面)にアプリ名 + ログアウト。コレクション上部にビュー切替チップ「一覧｜散布図」と登録アイコンボタン「＋」。
- 3-2 ビュー配置：① 単一メイン × 画面遷移。PC の散布図のみ「グラフ｜比較カード列」のペイン分割(比較は散布図ビューの一部であり、シングルは別画面)。
- 3-3 コレクション表示形式：一覧＝リスト(写真 + 名前 + 年齢・身長・カップ。概要把握と 1 件選択が目的、テキスト主体)。散布図＝自前 SVG(2 軸の比較が目的)。散布図のカードは比較カード(横/縦並びで同じスロット順)。
- 3-4 フィルタリング：なし(要件外。将来の検索・並べ替えは SPEC の将来項目)。
- 3-5 シングル表示形式：「そのものの情報」のみ。写真・名前 → 客観 3 値(年齢・身長・カップ) → 主観 3 軸(位置を示すバー)。
- 3-6 アクション：
  - Create：パラメーター型(新規状態のシングルで全項目を 1 画面入力して「保存」)。ウィザードは廃止(根拠不足)。
  - Update：モーダルエディット(「編集」で同ビューを編集状態にし「保存」で確定)。モードレスにしない理由：主観 3 軸はタッチドラッグで誤操作しやすく、保存の瞬間に他の全員の表示値が変わる(min-max 再正規化)ため、意図的な保存が必要。
  - Delete：アンドゥアブル(押した瞬間に一覧から消し、トーストで「元に戻す」を数秒出す。期限が切れてから実際に削除)。confirm ダイアログは廃止。
- 3-7 非同期・例外状態：末尾に列挙。
- 3-8 情報グループと優先順位：次項。

## 情報グループと優先順位
### 女優コレクション(一覧)
- まとまり：[行＝写真 + 名前 + (年齢・身長・カップ)]×N。上部に[ビュー切替 + 登録ボタン](文脈/道具)。
- 文脈：ヘッダー、ビュー切替。作業対象：行。
- 読み順：行の名前 → 行の客観値 → 次の行。
- 主アクション：登録「＋」(0 件のときは「最初の 1 人を登録」が主ボタン)。

### 女優コレクション(散布図)
- まとまり：[軸選択(横・縦)](引数) / [グラフ](作業対象) / [比較カード列](作業対象の要約)。
- 比較カード 1 枚の中身(スロット順を全カードで揃える)：写真(頭文字) → 名前 → 年齢・身長・カップ → 選択中 2 軸の値(例「身長 159cm ・ 顔 89」)。カード全体がシングルへのリンク。固定中のカードだけ右上に補助操作「×」(外す)。ホバー中(未固定)のカードは薄く表示して「×」を出さない。
- PC で 2 人以上固定しているときだけ、カード列の上に「固定中 n 人」と補助操作「すべて外す」を出す。スマホは常に 1 枚なので出さない。
- カードが 0 枚のとき：PC は「点にカーソルを合わせると表示、クリックで固定」、スマホは「点をタップすると表示」の補助文 1 行(操作しないと分からないため)。
- 読み順：グラフ → ホバー/固定中のカード → 軸選択。
- 主アクション：なし(点の選択が主操作。塗りボタンは置かない)。登録「＋」は一覧と同じ位置に置く。

### 女優シングル(閲覧)
- まとまり：[写真 + 名前] / [年齢・身長・カップ](1 行) / [肉付き・骨格・顔](ラベル + 両端 + 位置バー ×3) / [編集] / [削除]。
- 文脈：ヘッダーの戻り(‹ 一覧／‹ 散布図)。作業対象：上記。
- 読み順：名前 → 写真 → 客観 3 値 → 主観 3 軸。
- 主アクション：編集(従。塗りにしない。閲覧がゴールなので主ボタンは置かない)。削除は文字だけ + danger。

### 女優シングル(編集・新規)
- まとまり：[写真 + 名前] / [生年月日・身長・カップ] / [肉付き・骨格・顔のスライダー 3 本] / [保存 + キャンセル]。
- 入力要素(確定)：写真＝アバター + 従操作「写真を選ぶ／写真を変更」+ 補助操作「写真を外す」(写真があるときだけ)。名前＝テキスト。生年月日＝date、身長＝number(横並び)。カップ＝2 モードを維持(select A〜L ＋ バスト cm 入力と従操作「cm から目安」。補足文は出さない)。主観 3 軸＝相対スライダー(既存登録者を正規化位置に並べ、本人をドラッグ)。
- 同名の警告「同じ名前の人が既に登録されています(そのまま登録できます)」(既存文言のまま)は名前欄の直下に 1 行(登録の判断に影響するため)。
- 読み順：名前 → 客観値 → 主観 3 軸 → 保存。
- 主アクション：保存(primary 塗り、1 つ)。キャンセルは文字だけ。ヘッダーの戻りもキャンセルと同じ扱い(変更点 18)。
- 1 画面に収める(スクロールなし。要件)。

### ログイン
- まとまり：[アプリ名] / [Google でログイン]。主アクション：ログイン。

## 新しいユーザー体験のステップ(メインフロー。括弧は対応する変更点番号)
1. ユーザーは「Google でログイン」を押す
2. システムは女優コレクション(一覧)を表示する。上部に「一覧｜散布図」の切替と「＋」(1, 2, 7)。0 件なら「まだ誰もいません」と主ボタン「最初の 1 人を登録」
3. ユーザーは「＋」を押す → シングル(新規状態)で写真・名前・生年月日・身長・カップ・主観 3 軸を 1 画面で入力 →「保存」(4, 5)
4. システムは一覧へ戻す(要件)
5. ユーザーは「散布図」を押し、横軸・縦軸を選ぶ。PC はホバーでカード、クリックで固定(複数)。スマホはタップで最も近い 1 人(11, 12)
6. ユーザーはカード(または一覧の行)を押す → シングル(閲覧)。ヘッダーの「‹ 一覧／‹ 散布図」で来たビューへ戻る(3)
7. ユーザーは「編集」を押す → 同じ画面が編集状態になる →「保存」で閲覧状態に戻る／「キャンセル」で破棄(4, 5)
8. ユーザーは「削除」を押す → 即座に来たビューへ戻り、トースト「{名前} を削除しました［元に戻す］」が 6 秒出る(6)

## 既存UIからの変更点リスト
1. 下部タブバー「一覧／散布図／追加」を廃止し、コレクション上部のビュー切替チップ「一覧｜散布図」に置き換える
2. 「追加」はナビから外し、ビュー切替の右に「＋」アイコンボタン(従操作の見た目)として置く
3. ヘッダーをナビ面として地と区別する(面色 + 罫線)。シングル画面ではヘッダー左に来たビューへの戻り「‹ 一覧／‹ 散布図」を置く
4. 詳細画面と編集画面を 1 つのシングルビューに統合(閲覧状態 ⇄ 編集状態)
5. 追加・編集の 2 ステップを廃止し 1 画面にする。「次へ」「戻る」を削除、「保存」「キャンセル」にする
6. 削除の confirm を廃止し、即時削除 + トースト「元に戻す」にする
7. 一覧の行をカード(枠線)からリスト行(余白区切り)にする
8. 詳細の stat ボックス 6 個を「客観値 1 行 + 主観 3 軸のバー」に置き換える(枠を外す)
9. 相対スライダーのカード枠を外し、余白と見出しでまとまりを作る
10. 補足文を削除：「長辺 400px に縮小して保存します」「バスト cm からの換算は…現在: X」「他の人のアイコンをタップすると…」「まず 1 人登録すると…」「1 人登録すると散布図に点が出ます。」
11. 散布図：スマホはタップした最も近い 1 人だけを表示(複数固定なし)
12. 散布図の比較カードの「×」をカード内の補助操作として揃え、カードは面色のみ(枠線なし)にする
13. 文字サイズを 1 画面 3 種以内に整理(見出し 18 / 本文 16 / 補助 13)。例外：散布図(SVG)内の目盛り・軸ラベルは描画面と一緒に等倍で拡大縮小するため固定 px にできない(viewBox 上 12。スマホで約 12px、PC で約 22px)
14. 主ボタン(primary 塗り)は 1 画面 1 つ：ログイン「Google でログイン」、一覧(0 件)「最初の 1 人を登録」、編集「保存」。詳細の「編集」は枠線に下げる
15. 散布図の軸と固定状態を画面を離れても保持する
16. 写真のボタン文言を「選ぶ／変更／削除」から「写真を選ぶ／写真を変更／写真を外す」にする(「削除」を女優の削除と区別する)
17. 「目安にする」を「cm から目安」にする(補足文を消すため、ボタン自体で意味が分かる文言にする)
18. 編集・新規状態でもヘッダーの戻り(‹ 一覧／‹ 散布図)は残す。押すと「キャンセル」と同じく未保存の入力を破棄して来たビューへ戻る(離脱経路を塞がない)

### 維持する既存要素(変更しない)
- カップの 2 モード入力(select ＋ バスト cm →「cm から目安」)
- PC の「固定中 n 人」「すべて外す」(2 人以上固定時のみ)、固定カードの「×」
- 相対スライダーの挙動(既存登録者のアイコンをタップすると名前、両端の外側にも置ける)
- 同名の警告文
- 散布図のホバー/固定の当たり判定

## 見せない情報
- 一覧：生年月日の生の日付、主観 3 軸の値、写真の有無
- 散布図カード：生年月日、主観軸の生スコア
- シングル：内部 ID、作成日時、生スコア(正規化値だけ)、写真の縮小仕様
- 編集：ステップ番号、正規化の仕組みの説明

## 未決事項
- 同名の登録の警告文は維持する(登録可否に影響するため)

## 非同期・例外状態
| 状態 | 表示内容 | ユーザー操作 | 有効な主ボタン |
|---|---|---|---|
| 読み込み中(コレクション取得中) | 作業領域に「読み込み中…」1 行(muted) | 不要(待つ) | なし |
| 読み込み失敗 | 作業領域にエラー文(danger)。コレクションは出さない | 再読み込み(ブラウザ) | なし(UI 側で再試行を発明しない) |
| 0 件 | 「まだ誰もいません」+ 主ボタン「最初の 1 人を登録」。「＋」は出さない | 登録へ進む | 「最初の 1 人を登録」 |
| 1 人目の相対指定(基準なし) | スライダー下に「最初の 1 人なので基準はありません。だいたいの位置で構いません。」 | 任意の位置に置く | 「保存」 |
| 写真変換中 | 写真ボタンが「変換中…」で無効 | 待つ | 「保存」は有効のまま。変換中に保存すると選択中の写真は使われず、写真は変更なし扱い(既存写真があればそのまま) |
| 写真変換失敗 | 「画像の変換に失敗」をエラー文として写真ボタンの下に出す。写真は変更なし扱い | 別の写真を選び直す／そのまま保存 | 「保存」 |
| 必須未入力(名前・生年月日・身長のいずれか) | 「保存」を無効(押せない見た目)。エラー文は出さない | 入力する | なし(入力が揃うと「保存」が有効になる) |
| 保存中 | 「保存」が「保存中…」で無効、「キャンセル」も無効 | 待つ | なし |
| 保存失敗 | 編集状態に留まり、入力を保持したまま下にエラー文 | 直して再度「保存」 | 「保存」 |
| 削除の取り消し待ち(6 秒) | 一覧から消え、トースト「{名前} を削除しました」+「元に戻す」 | 「元に戻す」で復帰、放置で確定 | なし(トーストの「元に戻す」は補助操作) |
| 削除失敗(猶予後の実削除が失敗) | 来たビューのコレクションに当人を戻し、作業領域にエラー文 | もう一度「削除」 | なし |
| 見つからない(ID 不正) | 「見つかりません」+ 主ボタン「一覧へ」 | 一覧へ戻る | 「一覧へ」 |
| ログイン失敗 | ログイン画面のボタン下にエラー文 | もう一度「Google でログイン」 | 「Google でログイン」 |
